This repository contains a C#/.NET invoice management system developed during an internship in 2023.

The project includes a .NET application and a Web API component for managing invoice-related workflows. It uses C#, SQL/database integration, and layered project structure with models, repositories, controllers, and API components.

## Features

- Invoice management system
- .NET application structure
- Web API component
- SQL/database integration
- Repository-based data access
- Model-based domain structure
- API controllers
- Visual Studio solution organization

## Technologies

- C#
- .NET
- ASP.NET Web API
- SQL
- Visual Studio

## Project Structure

- `InvoiceSystem/` — main application logic, models, repositories, and invoice-related components
- `InvoiceSystemAPI/` — Web API layer with controllers and API configuration
